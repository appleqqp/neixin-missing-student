# 消失的學生：校園迷蹤（內新國小版）使用說明

原作：李宜玲老師（Genially）｜改編：內新國小版

## 資料夾裡有什麼
- `index.html`：遊戲本體（直接用瀏覽器打開就能玩）
- `data.js`、`assets/`：遊戲內容與圖片、音效（要和 index.html 放在一起）
- `排行榜後台_AppsScript.gs`：全班排行榜要用的 Google 試算表程式

## 計分規則
- 開始時輸入「班級」和「暱稱」
- 起始 100 分，每答錯一次扣 5 分（在 index.html 的 `SCORE` 可以改）
- 破案（走到 END）後自動上傳成績；排名：分數高的在前，同分比用時
- 老師要投影排行榜：在遊戲網址後面加上 `#rank`，例如 `https://你的網址/index.html#rank`（每 15 秒自動更新），也可以按左下角「🏆 排行榜」

---

## 第一步：建立 Google 試算表排行榜（約 5 分鐘）
1. 用學校 Google 帳號開一份新的 Google 試算表，取名例如「消失的學生排行榜」。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把編輯器裡原本的內容全部刪掉，貼上 `排行榜後台_AppsScript.gs` 的全部內容，按儲存。
4. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按「部署」，第一次會要求授權，用自己的帳號允許（若出現「Google 尚未驗證這個應用程式」，按「進階」→「前往（不安全）」，這是你自己的程式）。
6. 複製「網頁應用程式」網址（`https://script.google.com/macros/s/……/exec`）。
7. 用記事本打開 `index.html`，找到這一行，把網址貼進引號裡，存檔：
   ```
   SCORE_URL: '',
   ```
   改成
   ```
   SCORE_URL: 'https://script.google.com/macros/s/……/exec',
   ```
- 要清空排行榜：到試算表的「排行榜」工作表，刪掉第 2 列以下的資料。
- 學生的暱稱會出現在排行榜上，建議請學生用「座號＋暱稱」，不要填全名。

## 第二步：把遊戲放上網（擇一）
學生的成績要送到 Google 試算表，遊戲需要放在一般的網頁空間（Claude 的作品連結會擋掉對外連線，那邊只能用「本機排行榜」）。

**GitHub Pages（免費，推薦）**
1. 登入 GitHub → 右上「+」→ New repository，取名例如 `neixin-game`，選 Public，建立。
2. 在新 repo 頁面按「uploading an existing file」，把整個資料夾內容（index.html、data.js、assets 資料夾）拖進去 → Commit。
   - 網頁一次最多上傳 100 個檔案；assets 有 89 個檔案，可以分兩次上傳。
3. 到 Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save。
4. 約 1～2 分鐘後，網址會是 `https://你的帳號.github.io/neixin-game/`，把這個網址給學生。

**其他方式**：學校網站主機、Netlify 等可以放靜態網頁的地方都可以，整個資料夾原封不動上傳即可。

## 沒有設定 SCORE_URL 時
排行榜會變成「本機模式」：只記錄在同一台電腦、同一個瀏覽器裡，適合電腦教室同一台電腦輪流玩。
